# morning

Утренний прогон: пять проверок и один вывод. Задача - за десять минут узнать, что изменилось за ночь, и назвать дело дня. Это не планирование недели и не разбор задач.

## Прогон

| # | проверка | что именно | кто делает |
| --- | --- | --- | --- |
| 1 | почта | непрочитанное, что требует ответа сегодня, что можно закрыть в одну строку | агент |
| 2 | календарь | что сегодня, во сколько первое, что переносится | агент |
| 3 | посылки | Nova Poshta: в пути · прибыло · лежит на отделении и горит срок хранения | вручную |
| 4 | работа | что взято, что висит на ревью, что кем-то заблокировано | агент |
| 5 | тело | сон, самочувствие, лекарства, записи и анализы | ты |

Порядок не менять: сначала внешнее и просроченное (1-3), потом своё (4), потом состояние (5). Иначе день собирается из того, что первым попалось на глаза.

## Вывод

Одна строка - **дело дня**. Не список: список даёт паралич.

Сверка по [strategy](/doc/strategy): обслуживает ли это дело вещь, которую довожу до внешнего суда? Если за прогон не нашлось ни одного такого дела - это сигнал, а не обычное утро.

## Статус автоматизации

| шаг | сейчас | чего не хватает |
| --- | --- | --- |
| почта | агент читает напрямую | ничего, работает |
| календарь | агент читает напрямую | ничего, работает |
| посылки | руками в приложении | задача `runtime/tasks/nova-poshta.ts` + ключ API из личного кабинета |
| работа | агент читает git и трекер | сводка одной командой |
| сборка прогона | нет | задача, которая гоняет 1-4 и кладёт результат нодой в дерево |

Утренний прогон = задача в `runtime/tasks/` плюс launchd plist со `StartCalendarInterval`, который зовёт `npm run cli run <task>`. launchd, в отличие от cron, догоняет пропущенный запуск после сна ноутбука (`man launchd.plist`).
