-   **Умберто Еко - «Трактат із загальної семіотики» (A Theory of Semiotics)** - самая амбициозная попытка построить единую теорию знаковых систем. Если брать одну «большую» книгу - это она.
-   **Юрій Лотман - «Всередині мислячих світів» / концепция семиосферы** - [книга тут](/bin/lotman semiosfera.fb2)
  
андрій платонов - «вязкий, остранённый» язык; второй полюс сравнения  
лоренс стерн, «трістрам шенді» - европ. дед манеры: дигрессия как структура, типографическая игра, автор влезает в собственный текст  
  
**русский андеграунд / маргиналы**  
саша соколов («школа для дураков», «палисандрия», «между собакой и волком») - ближайший по фактуре: плотная каламбурная орнаментальная «проза поэта», логорея, самомифологизация; точный матч ткани → начинай отсюда  
алексей ремізов - орнаментальный сказ, архаичная орфография, рукотворные книги-объекты с собственными рисунками; почти прямой предок ханона по «книга-объект»  
дмитрий галковский, «бесконечный тупик» - гипертекст примечаний-к-примечаниям, самиздат культовый объект, автор-персонаж, параноидальная эрудиция; ближе всего по «компендиум»  
венедикт єрофєєв, «москва–петушки» - ироничная пьяная эрудированная дигрессия, самиздат  
  
**украинский андеграунд**  
майк йогансен - полимат (поэт/прозаик/переводчик/критик/лингвист); «подорож ученого доктора леонардо…» - метапроза, автор играет с собственным текстом; исторический укр. матч  
юрій іздрик, «воццек» - «соревнование с языком», текст-лабиринт страниц/строк/слов/букв/звуков, множественность «я»; станиславский феномен, журнал «четвер»; плотный, каламбурный, самомифологичный; заходить с «АМтм», не с «воццека»  
емма андієвська - эмигрантский сюрреализм, неологистическая герметичная плотная проза  
  
**британский / ирландский**  
алаздер ґрей («lanark», «poor things») - типографическая игра, самоиллюстрированные книги-объекты, авторская интрузия («index of plagiarisms»), самомифологизация; сильный по «книга-объект», читабельный  
фленн оʼбрайен («at swim-two-birds», «the third policeman») - метафикция, сноски-как-отдельный-роман (de selby), комическая дигрессия, эрудированный абсурд; самый лёгкий вход, смешно  
ентоні берджесс - логофил, изобретённое арго (nadsat в «заводном апельсине»), плотная звуковая проза  
  
**американский**  
вільям ґасс («the tunnel», «willie masters' lonesome wife») - проза-как-объект, типографика, одержимость звуком слова, лексическая плотность; «плотность» + «книга-объект»  
александр теру («darconville's cat») - лексический максимализм, списки, избыток эрудиции; самый чистый матч по плотности словаря  
девід марксон (поздние «notecard novels»: «wittgenstein's mistress», «reader's block») - фрагмент-компендиум эрудиции, самореферентность; «компендиум»  
марк z. данілевський, «house of leaves» - типографический лабиринт, сноски-в-сносках, книга-как-дом; современный матч по «книга-объект»
