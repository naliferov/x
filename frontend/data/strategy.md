# strategy

Главная заметка: чему всё подчинено. Стратегия продукта - отдельно, в [x strategy](/doc/x-strategy).

Цель: за 90 дней довести одну вещь до внешнего суда - деньги, пользователь или явный отказ.
Эффективность и продуктивность - средство под эту цель, не цель.

## Цель обязана уметь провалиться

| | |
| --- | --- |
| результат | одна вещь, отгруженная наружу |
| горизонт | 90 дней |
| судья | внешний: деньги / пользователь / явный отказ |
| kill-критерий | нет внешнего сигнала за 90 дней → вещь закрыта, не продлена |

Отказ = результат. Отсутствие суда = не результат.

## Вещь - выбрать одну

| кандидат | откуда | что считается судом |
| --- | --- | --- |
| 15-20 разговоров по Mom Test + kill-критерий наперёд | [x strategy](/doc/x-strategy) §5 - написано, не выполнено | боль подтверждена деньгами или нет |
| productized service: фикс-прайс аудит миграции | x strategy §3 | первая оплата |
| закончить «собаку на заводі» | [sense](/doc/sense) | опубликовано |

Не выбрано. Пока не выбрано - цели нет, есть режим.

## Почему не «экстремальная эффективность» как цель

| претензия | суть |
| --- | --- |
| не отсеивает | под продуктивность подводится всё: здоровье → работоспособность, философия → мышление, музыка → выход. критерий, который оставляет всё, не критерий |
| не то узкое место | [sense](/doc/sense): «страх - не лінь, а страх суду над реалізованим», «колекції = кладовище ненароджених сенсів». [x strategy](/doc/x-strategy): «естетичний перфекціонізм проти відвантаження». тормозит не скорость, а доведение до судимого |
| слово формы | sense: «форма попереду сенсу, тікаю у форму, бо там я майстер». оптимизация процесса - самое комфортное укрытие для мастера формы |
| «экстремальная» | добавляет режим, не цель. упирается в пропускную способность - медицинские пункты в [todo](/doc/todo) |

Эффективность разгоняет машину. Если машина копит потенциал - быстрее копит.

## Фильтр

Один вопрос ко всему - к заметке, задаче, покупке, идее:

обслуживает ли это вещь, которую я довожу до конца сейчас?

| ответ | что делать |
| --- | --- |
| да | оставить |
| нет, но это вход - сон, еда, деньги, здоровье | оставить, не трогать |
| нет, это «пригодится» | потенциал, не работа - в архив |

Третья строка - основная масса. Коллекция ссылок ощущается как работа и ею не является.

## Роль эффективности

Средство. Ниже цели, выше комфорта.

| работает на | не работает на |
| --- | --- |
| меньше переключений | больше часов |
| меньше незакрытых веток | больше собранного |
| короче путь «понял» → «отгрузил» | лучше устроенный инструмент |

Признак подмены: неделя ушла в улучшение процесса, судимого результата не прибавилось.
