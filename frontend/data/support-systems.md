# support systems

Тикет-системы поддержки. Все каналы → одна очередь + история обращения + автоматизация вокруг неё.

## Ядро (есть у всех)

| блок | из чего |
| --- | --- |
| каналы → одна очередь | почта, чат, телефон, соцсети, мессенджеры |
| тикет | история, статусы, приоритет, назначение на сотрудника |
| автоматизация | правила маршрутизации, SLA-таймеры, эскалации, макросы |
| база знаний | публичная - клиентам, внутренняя - операторам |
| самообслуживание | портал |
| отчётность | время реакции, время решения, нагрузка, CSAT |
| интеграции | CRM, биллинг, продукт |

## Чем реально различаются

| система | отличие |
| --- | --- |
| Zendesk | кастомизация вглубь + зрелые интеграции, дорого |
| Freshdesk | то же дешевле и проще, слабее в сложных процессах |
| Intercom | сильнее в чате внутри продукта, слабее в классическом тикетинге |
| Zoho Desk | дешевле всех, интерфейс беднее |
| Front | общий инбокс вместо тикетов - для команд с личной перепиской |
| Plain, Pylon | работа через Slack Connect с клиентом, а не через портал |

Ядро одинаковое; различие = где глубина: процессы (Zendesk) · цена (Freshdesk, Zoho) · канал (Intercom, Front, Plain/Pylon).
