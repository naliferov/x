# ai

## Что это и где граница

- **Vibe coding vs vibe engineering.** По Уиллисону: vibe coding = писать с LLM **не читая код**. Как только читаешь, тестируешь и можешь объяснить - это уже не vibe coding.
- **Спека-ритуал сам по себе качество не двигает.** Двигают заземление в контекст и гейты валидации поверх. SDD без этих двух - обряд.
- **Мульти-агенты: вширь да, вглубь нет.** Работают на широких параллельных задачах, на кодинге - явно плохо.

## Как работать

- **Агент внутри инструмента, не вокруг** - воронку строй _в_ Amplitude; не «экспорт → спроси агента → веришь непроверенному».
- **OpenSpec (лёгкий) vs Superpowers (тяжёлый: гейты, worktree, TDD, сравнение вариантов)** - выбирай по цене/времени/качеству. Не строй свой SDD.
