## "use strict"

-   Disallows implicit globals
-   Makes this undefined in functions
-   Prevents duplicate parameters
-   Makes certain silent errors throw exceptions
-   Disallows with
-   Restricts eval

## semicolons

semicolon may be omitted in most cases when a line break exists. But this wouldn’t work:

```
alert("Hello")
[1,2].forEach(alert)
```
